# Jacykow.github.io

Jacek Gulij's personal site, live at <https://www.gulij.com> via GitHub Pages.
No build step: what is committed here is what is served.

* `/` — the portfolio page
* `/random/` — **Random Engine**, a dice-notation console with no dependencies
  and no network calls. Its own [README](random/README.md) is the full
  specification of the notation.

```bash
node serve.js     # the whole site on http://localhost:5173
```
